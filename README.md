# Pausa de bienestar

Portada común y Mi pausa para GitHub Pages.

- La portada enlaza al check-in original en https://pausadebienestar.me. El sitio y su historial permanecen en Sites.
- Mi pausa está en `mi-pausa/`: momento, emoción, posible razón, necesidad y acción.
- Guardado voluntario en localStorage (`mi-pausa-history-v1`). No hay servidor de respuestas ni sincronización. Los datos pueden perderse al borrar el almacenamiento del navegador.
- Esta implementación de Mi pausa se reconstruyó a partir de los requisitos de la conversación; los archivos adjuntos originales no estaban disponibles.
- El código público no incluye respuestas personales, credenciales ni la base de datos del sitio original.

## Publicación
GitHub Pages: rama main, carpeta raíz. `.nojekyll` permite servir los archivos estáticos directamente. Las rutas de CSS, JavaScript, icono y navegación son relativas para funcionar bajo `/pausa-bienestar/`.

## Desarrollo
Servir esta carpeta con un servidor estático. No requiere compilación ni dependencias.
